# Code of conduct

We want project discussions and contributions to be useful, respectful and welcoming.

- Treat people with respect regardless of background, identity, experience or ability.
- Give specific, constructive feedback about the work and be willing to reconsider.
- Respect privacy. Do not publish private messages, personal information or credentials.
- Avoid harassment, discrimination, threats, sexualized behavior, personal attacks and repeated disruption.
- Keep issues and pull requests focused on the project. Respect maintainers' time and boundaries.

This applies to repository issues, pull requests and other spaces maintained for this project. Maintainers may edit/remove content, close or lock discussions, reject contributions, or restrict participation to address violations. Responses should consider context and severity.

Report conduct concerns through a private contact method listed on [the maintainer's GitHub profile](https://github.com/Mahmoudmnb). If none is available, ask for a private contact channel without publishing details or identifying information. Security vulnerabilities use [SECURITY.md](SECURITY.md) instead. Reports are handled as privately as practical; no absolute confidentiality or response-time guarantee is promised.
