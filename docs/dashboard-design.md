# Dashboard design implementation

Source: [Figma Dashboard design](https://www.figma.com/design/yFT78AadBUhXvLXYTC7BDX), page `01 · Dashboard design`, exact nodes `2:2662`–`2:2681`. The initial implementation could not access the connector. The finishing run retrieved seven actual context/screenshot references, corrected those compositions and reused exact local SVG navigation assets. Thirteen comparisons are blocked by the Figma MCP Starter-plan call cap. See [dashboard-visual-review.md](dashboard-visual-review.md) for every node, evidence, viewport and adaptation; the original fallback-only review is historical.

Native Material 3 widgets implement the documented canvas, teal action, text, border and status palette. Manrope headings and Roboto body fonts are bundled, with their SIL Open Font License files under `dashboard/assets/fonts/`. No font download happens at startup. Page margins are 24 logical pixels, cards use 16-pixel radii, forms scroll and content is constrained to 840 pixels. All four persistent destinations retain state through an indexed navigation shell. Details/editors have native back buttons and dirty-form confirmation.

Screen mapping: login → auth; overview → reports; content/team/services/taxonomies/inbox/activity → resource lists with explicit resource filters; entry/member/settings/service/taxonomy/inquiry editors → explicit feature field sections with shared field controls; media/upload states → upload and image detail; analytics → five real report cards; More → management links; account → password/sign-out; empty/error/expired → shared states and session guard. No illustrative data is installed in live repositories.

Intentional adaptations: all contract fields appear in scrolling form sections, derived search preview is read-only, gallery has accessible up/down controls, relationship selections retain numeric IDs and paginate, contributor lists identify inactive profiles. Analytics uses labeled horizontal daily bars with count/date axes and textual values; it does not reproduce illustrative Figma bar heights. Null referrers and deleted entries receive explicit text. Settings save confirms immediate public visibility.

Automated responsive checks cover 360/412/840 widths and text scales 1/2, with real scrolling assertions. Device screenshots use fictional disposable content only. TalkBack speech, system picker activity recreation, and an exact Figma comparison require separate human/device review; automated widget layout success does not prove those checks.

Native screenshot review on 2026-10-21 inspected overview, login, More, analytics and settings against the plan's fallback tokens: headings, teal actions, borders, scrolling, UTC range and empty counts render correctly. Emulator captures are 1080×2274 app pixels (system chrome excluded) on the Pixel 7 AVD, approximately 412 logical pixels wide. They are evidence of native rendering, not Figma comparison images. At large phone text scales the four persistent destinations wrap into two rows to keep their labels readable. Daily zero-count chart tracks use a neutral color; filled teal represents actual counts.


Finishing evidence supersedes the initial fallback review where available. Updated captures and automated/native outcomes are in dashboard-evidence/native and dashboard-manual-qa.md. Human TalkBack and physical-device evidence remain separate open gates.
