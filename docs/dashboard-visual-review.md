Reference frame: 412 × 892 design units. Native capture: Android API 30, x86-64 emulator-5554, density 420 dpi; Flutter reports **411.4286 × 843.4286 logical pixels, DPR 2.625, top inset 24, bottom inset 0** in [metrics.json](dashboard-evidence/native/metrics.json). Flutter screenshots are 1080 × 2214 application pixels; the full Android display uses a temporary 1080 × 2340 override and includes system chrome. This is a near-matching width, shorter application viewport, not an 892-pixel application frame. Text scale is 1× unless named large-text; widget checks separately exercise exact 360/412/840 logical widths at 1×/2×. Scrolling/reflow differences are intentional; raw PNG pixels were not compared directly with design units. Emulator display/font settings are restored after QA.

Shared corrections: F7F8F6 canvas, white borderless 16-radius cards, Manrope headings, Roboto body, real status tints, 52-high primary actions and exact 24×24 Figma SVG navigation assets. [Asset manifest](dashboard-evidence/figma/assets.json) records source slots, dimensions and hashes. SVGs remain local vector widgets, not flattened screens. Screen 17 navigation assets are byte-identical to 03; selected Inbox artwork was not available, so the existing exact outline is retained with selected text/background/accessibility state. Navigation has an explicit semantic tap action and selection state. Real API behavior and reachable 48px targets take precedence over sample content density.
